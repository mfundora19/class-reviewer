# Prompt templates

This folder contains reusable prompts for generating, importing, and improving ReviewApp study content and analytics.

- [Material generator](./material-generator.md) — generate ReviewApp study content from source material.
- [Linux to Obsidian](./linux-to-obsidian.md) — convert Linux study material into Obsidian-ready notes.
- [Network to Obsidian](./network-to-obsidian.md) — convert networking study material into Obsidian-ready notes.
- [Stats polish](./stats-polish-prompt.md) — improve the Stats view and Markdown report.
